# **App Name**: Alpha Vision

## Core Features:

- Product Catalog: Display Sony camera models with key specs and images fetched from Firestore.
- Detailed Product Pages: Show in-depth specifications, image galleries, and related content for each camera model.
- Camera Comparison Tool: Compare specifications and features between different Sony camera models using data stored in Firestore.
- Enquiry Form: Allow users to submit inquiries about specific camera models, storing the submissions in Firestore.
- Model Recommendation Tool: Suggest a Sony camera model based on user needs using an AI tool and store the models and associated metadata in Firestore.

## Style Guidelines:

- Primary color: Deep gray (#333333) for a premium, cinematic feel.
- Background color: Very dark gray (#222222), almost black, to maintain a dark, cinematic aesthetic.
- Accent color: Light gray (#AAAAAA) to provide contrast and highlight key elements without being distracting.
- Headline font: 'Poppins', sans-serif, for a modern, clean, and premium look.
- Body font: 'Inter', sans-serif, to ensure readability and a contemporary feel.
- Use minimalistic icons that are white or light gray, aligning with the premium, clean aesthetic.
- Employ a grid-based layout to ensure content is well-organized and responsive across devices.
- Implement subtle animations on hover effects to add a layer of interactivity without overwhelming the user.
